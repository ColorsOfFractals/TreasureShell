TREASURESHELL
=============

INSTALLATION

1. Double-click TreasureShell-Setup.exe
2. Follow the Windows installer
3. Launch TreasureShell

TreasureShell is packaged as a self-contained Windows x64 application.

You do not need to install:
- .NET SDK
- Git
- NuGet
- Inno Setup
- PowerShell build tools

Just run the installer.

If Windows or antivirus software warns about the application, note that the current public build is not yet distributed with an established trusted-publisher code-signing reputation.
